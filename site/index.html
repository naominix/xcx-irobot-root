iRobot Root for Xcratch

Root rt0/rt1をScratchのブロックから動かす、Xcratch用Bluetooth拡張機能です。動きや色を目で確かめながら指定でき、日本語・にほんご（ひらがな）・英語、PC/macOSとiPadOSに対応します。

Root専用Xcratchで開く GitHubと詳しい説明

見て、触って、すぐ分かる

数値だけでは想像しにくいロボットの動きを、図と操作パネルで分かりやすくしました。マウスでも指でも操作でき、必要なときは正確な数値や目的地の座標も入力できます。

図をドラッグして動きを指定
小数・負数を直接入力
iPad用の画面内テンキー

Scratchらしさを保った操作

モーター、色、音階を視覚的に選べます。従来の数値入力や演算ブロックも引き続き使えるため、入門から高度な作品まで同じブロックで発展できます。

PCとiPadで共通

PCではマウス、iPadでは指で操作できます。数値欄をタップすると数字キーボードが開き、さらに画面内テンキーも選べます。

Root専用Xcratchと公式Xcratch

Root専用Xcratch

Root専用Xcratch では、モーター出力、移動距離、回転、円弧を図とスライダーで指定できます。数値の直接入力と画面内テンキーも利用できます。

公式Xcratch・Scrub

公式XcratchとApp Store版Scrubでも、すべてのRoot命令を利用できます。専用モーションピッカーがない環境では、同じブロックがScratch標準の数値欄として表示され、iPadではOSの数字キーボードで入力します。

互換性：専用UIはRoot専用Xcratchで提供する強化機能です。ブロックの命令と数値は共通なので、プロジェクトは公式XcratchとRoot専用Xcratchの間で利用できます。

実機なしで試せるRootシミュレーター

「制御モードをシミュレーターにする」ブロックを使うと、実機へBLE命令を送らずにRootの動きを専用キャンバス上で確認できます。「Rootシミュレーターを開く」で座標、向き、LED、マーカー状態を表示します。

動き・描画・LEDを再現

直進、回転、円弧、座標ナビ、マーカーの軌跡、LEDの点灯・点滅・回転を確認できます。実行速度は0.25〜4倍から選べ、「もう一度実行」で同じプログラムをすぐ試せます。

イベントの練習

壁とブロックの障害物を追加して、左右バンパーの衝突イベントを試せます。Rootの4つのタッチ領域をクリックまたはタップすると、タッチセンサーHATも確認できます。

実機接続を維持したまま使える

シミュレーター固定中は、接続済みのRootへ制御命令やセンサーイベントを送受信しません。BLE接続は維持できるため、実機モードへ戻るときに再接続は不要です。

始め方：「制御モードをシミュレーターにする」→「Rootシミュレーターを開く」→緑の旗、の順で実行します。実機を動かしたいときは制御モードを「実機」に戻してください。

はじめかた

  1. Rootの電源を入れ、端末の近くへ置きます。
  2. 上の「Root専用Xcratchで開く」を押します。公式Xcratchでも拡張機能URLを指定すれば利用できます。
  3. 「Rootに接続する」を実行し、一覧からRootを選びます。
  4. LEDや音を試してから、低速のモーター命令へ進みます。

ナビを使うとき：Rootをスタート地点へ置いてから「ナビをリセットする」を一度実行してください。ナビの途中でロボットを手で移動した場合、拡張機能が管理している現在地と実際の位置がずれるため、スタート地点を決め直してもう一度リセットします。

App Store版Scrubは無改造で利用できます。 Rootとmicro:bit More v2の同時接続も実機確認済みです。接続先のWebエディターには標準Scratch Linkマーカーが必要ですが、公式Xcratchは2026年8月7日現在、この条件に対応済みです。詳しくはGitHubのREADMEを確認してください。

主な機能

動かす・座標ナビ

Rootの動きを図で確認しながら、左右モーター、距離、回転、円弧を指定できます。位置をリセットし、開始地点からのX・Y座標（cm）へ移動するナビブロックにも対応します。

光・音・描画

カラーピッカーまたはRGB値でLEDの点灯・点滅・回転を指定し、発音、マーカーと消しゴムを制御します。

イベント

左右バンパー、4か所のタッチ、崖、バッテリー通知をHATブロックで受け取ります。

複数台から選択

近くのRootを検索し、デバイス一覧から接続先を選べます。
